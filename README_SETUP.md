# Beauty Manager Bot — установка на Render

## 1. Файлы
Замени в GitHub-репозитории `beauty-manager-bot` файл `main.py` на этот `main.py` и замени `requirements.txt`.

## 2. Render
Start Command:
```bash
uvicorn main:app --host 0.0.0.0 --port $PORT
```

Environment Variables:
- `TELEGRAM_BOT_TOKEN` — уже созданный токен BotFather
- `OPENAI_API_KEY` — твой OpenAI API key
- `OPENAI_MODEL` — можно оставить `gpt-5.6-luna`
- `DEFAULT_TIMEZONE` — `Europe/Moscow`

## 3. Telegram-канал
1. Добавь `@BeautyManager_Moscow_Bot` в свой канал как администратора.
2. Дай право публиковать сообщения.
3. Открой бота и нажми `📢 Канал`.
4. Перешли боту любой пост из своего канала.
5. Бот автоматически сохранит ID канала.

## 4. Как добавлять товар
Нажми `➕ Новый товар`.

1. Фото товара.
2. Фото товара с упаковкой (если есть).
3. Цена и количество, например: `7500 ₽, 2 шт.`

Бот:
- анализирует фотографии;
- определяет товар и категорию;
- проверяет информацию через веб-поиск;
- ставит категорийный хэштег в первую строку (`#парфюм`, `#румяна`, `#тональный_крем` и т.д.);
- оформляет карточку;
- использует 2 фото;
- распознаёт готовые наборы как одну позицию;
- ждёт твоего `✅ Одобрить`;
- только после одобрения ставит публикацию в очередь.

## 5. Расписание
По умолчанию: каждый день в `10:00`, `15:00`, `20:00` по Москве.

Из меню `⏰ Расписание` можно поменять:
- дни;
- время;
- часовой пояс;
- поставить автоматическую публикацию на паузу.

## Важно
Этот вариант использует SQLite (`beauty_manager.db`). На обычном Render Web Service без persistent disk файл может потеряться при пересоздании/замене инстанса. Для постоянной истории, очереди и статистики следующий технический шаг — перенести базу на Render PostgreSQL.

Также автоматическое расписание требует, чтобы сервис реально работал в момент публикации. Если Render усыпляет сервис на выбранном тарифе, публикации в этот период не сработают.
